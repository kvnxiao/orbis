# Repository research

These documents record the evidence behind repository-wide standards and library choices. Each one
is dated and states the versions it inspected. Research is informative: the
[specification guide](../specifications.md) and the agent instructions state the current rules, and
the [wiki decision records](https://github.com/kvnxiao/orbis/wiki) explain them.

| Document                                        | Question it answers                                                                                                      |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| [Package specifications](specifications.md)     | Which specification practices and empirical results inform how Orbis writes package contracts?                           |
| [Implementation plans](implementation-plans.md) | How do Codex, Claude Code, and Pi planning extensions structure implementation plans, and what transfers to Orbis?       |
| [Effect v4](effect-ts-v4.md)                    | What does Effect v4 add for Pi extension workflows, which host constraints apply, and what does it cost to load and run? |
